                                                                             Madhav Sales E-Commerce Dashboard

This project showcases an interactive E-Commerce Sales Dashboard designed to analyze business performance across multiple dimensions such as revenue, profit, customer behavior, and product categories. The dashboard provides a comprehensive view of key metrics to support data-driven decision-making.

 Key Features:
KPI Metrics Overview:
Displays important business indicators including:
Total Sales Amount (161K)
Total Quantity Sold (2008)
Total Profit (26K)
Average Order Value (44K)
State-wise Sales Analysis:
A horizontal bar chart highlighting top-performing states like Maharashtra, Madhya Pradesh, and Delhi.
Monthly Profit Trends:
A column chart showing profit distribution across months (January–March), helping identify performance trends.
Category-wise Quantity Distribution:
A donut chart representing contribution of categories such as Clothing, Electronics, and Furniture.
Customer-wise Sales:
A bar chart identifying top customers contributing to revenue.
Payment Mode Analysis:
A donut chart showing usage of different payment methods like COD, UPI, Debit Card, EMI, and Credit Card.
Sub-Category Profit Analysis:
A bar chart comparing profit generated from sub-categories like Printers, Phones, Accessories, Bookcases, and Sarees.
Interactive Filters:
Includes slicers for Quarter and State to dynamically explore the data.
Insights:
Clothing dominates sales with the highest quantity share (~63%).
COD (Cash on Delivery) is the most preferred payment method (~44%).
Maharashtra is the leading state in terms of sales.
Printers and Phones generate the highest profit among sub-categories.
Profit shows a slight decline from January to March.
 Tools & Technologies:
Microsoft Excel / Power BI (for dashboard creation)
Data Visualization Techniques
Data Cleaning & Transformation
 Purpose:

This project demonstrates the ability to build interactive dashboards, analyze e-commerce data, and extract meaningful insights to support business growth and strategy.
